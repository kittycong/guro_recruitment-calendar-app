# 채용 달력 관리 웹앱

구로장애인자립생활센터 채용 일정 관리용 정적 웹앱입니다.

## 실행 주소

현재 로컬 실행 주소:

```text
http://127.0.0.1:4173/
```

## 로컬 실행

```powershell
cd outputs\recruitment_calendar_app
python -m http.server 4173 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:4173/`으로 접속합니다.

## 주요 기능

- 긴급/일반 공고 기준 자동 일정 생성
- 서류마감 및 면접 일정 달력 표시
- 면접 대상자 개별 관리
- 칸반/타임라인 보기
- 시행번호 기반 HWPX 공고 생성
